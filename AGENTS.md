
# AGENTS.md

## Project context

This repository contains a small web studio portfolio
and two demonstration websites.

The project is developed by two people:
- Anton: frontend development and deployment.
- Arseniy: UI/UX design and Figma layouts.

## Technology stack

Use:
- HTML5
- CSS3
- Vanilla JavaScript

Do not add frameworks, package managers, build tools,
or external dependencies without explicit approval.

## Code requirements

1. Use semantic HTML elements.
2. Keep HTML, CSS and JavaScript readable.
3. Prefer simple solutions over complex abstractions.
4. Use descriptive class and variable names.
5. Support screen widths starting at 320px.
6. Avoid unnecessary animations.
7. Do not change unrelated files.

## Accessibility

- Use appropriate heading hierarchy.
- Provide alt text for meaningful images.
- Keep interactive elements keyboard accessible.
- Use visible focus states.
- Associate form labels with inputs.

## Content rules

- Never invent real clients, testimonials or results.
- Clearly label demonstration projects.
- Do not use copyrighted assets without permission.
- Do not introduce fake working forms or buttons.

## Security

- Never commit passwords, tokens or API keys.
- Do not collect personal data unnecessarily.
- Validate user input in calculators and forms.

## Workflow

Before making changes:
1. Inspect the relevant files.
2. Explain the proposed changes briefly.
3. Identify the files that will be modified.

After making changes:
1. Summarize the changes.
2. Show or describe the diff.
3. Run available checks.
4. Report what was and was not tested.
5. Do not claim successful browser testing unless
   browser testing was actually performed.

## Learning requirement

When implementing unfamiliar code, briefly explain
the key HTML, CSS or JavaScript concepts used.

## Definition of done

A task is complete only when:
- The requested functionality is implemented.
- No unrelated files were changed.
- Relevant checks have been performed.
- Known limitations are documented.
