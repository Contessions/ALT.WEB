# Изображения FORMA

Оба кадра созданы с помощью генератора изображений OpenAI 21 ноября 2026 года специально для демонстрационного кейса ALT Web. Авторские фотографии чужих студий не использовались. Подпись к изображениям для портфолио — «Визуализация концепта».

- `hero.jpg` — графитовый автомобиль при инспекционном освещении. Главный объект справа, свободная зона для текста слева.
- `detail.jpg` — иллюстрация полировки кузова. Для блока процесса, не для документального сравнения до и после.
