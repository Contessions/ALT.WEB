# Мера

Второй демонстрационный кейс ALT Web. Каталог из девяти моделей с восемнадцатью исполнениями, проверка места и предварительная смета. Первая версия оформления использует редакционную съёмку интерьеров, тёплый фон и терракотовые отметки.

## Запуск из корня ALT Web

Архив кейса распакуйте в папку ALT Web, чтобы `work.html` и `cases/furniture/` оказались на своих местах. Сам магазин также открывается прямо из извлечённой папки `cases/furniture/`.

- Откройте `cases/furniture/index.html` в браузере для статической версии. В студии ссылка есть на `work.html#furniture-case`.
- Запустите `node cases/furniture/server.mjs` на Node.js 22 или новее, затем откройте [http://127.0.0.1:8080/cases/furniture/](http://127.0.0.1:8080/cases/furniture/). При необходимости смените порт через переменную `PORT`. Установки пакетов нет.
- Для GitHub Pages достаточно файлов из репозитория. Там каталог, смета и проверка места работают в браузере. Node-сервер служит для запуска с API.

## Где вносить изменения

| Файл | Содержание |
| --- | --- |
| `index.html`, `styles.css` | Разметка, шаблон карточки и базовые стили. Цвета заданы переменными в начале CSS. |
| `assets/` | Сгенерированные иллюстрации интерьеров и моделей, оптимизированные в WebP. |
| `catalog.js` | Комнаты, типы мебели, модели, исполнения, размеры в сантиметрах и цены в рублях. |
| `engine.js` | Фильтрация, проверка размеров, подсчёт количества и суммы по каталогу. Один и тот же код выполняется в браузере и на сервере. |
| `app.js` | Поля формы, действия карточек, сохранение сметы и скачивание файла. |
| `server.mjs` | HTTP-сервер и JSON API. |
| [research.md](research.md) | Разбор двадцати сайтов и решения для кейса. |

Цена хранится на уровне исполнения. Например, измените `price` у `lento / olive-210` в `catalog.js`, обновите страницу и выберите «Велюр, оливковый». Новая цена должна появиться в карточке, смете и скачиваемом файле. При использовании API сначала перезапустите сервер, чтобы он перечитал каталог.

Идентификаторы модели и исполнения используются в сохранённой смете. При изменении цены сохраняйте идентификатор. Исполнения, удалённые из каталога, пропускаются при восстановлении сметы.

## API

Все маршруты начинаются с `/cases/furniture/api/`.

| Метод | Путь | Входные данные |
| --- | --- | --- |
| GET | `catalog` | Необязательные параметры `query`, `room`, `category`, `width`, `depth`, `price`, `sort` (`catalog` или `price`). Выдача содержит подходящие исполнения каждой модели. |
| POST | `fit` | JSON с `productId`, `variantId`, `width`, `depth`, `passage`. Возвращает остатки по двум осям и результат для двух положений. |
| POST | `quote` | JSON с массивом `items`. Каждая позиция содержит `productId`, `variantId`, `quantity`. Сервер берёт цены из каталога. |

## Проверка руками

1. В каталоге выберите гостиную, диваны и ширину до 200 см. Останется один вариант дивана Ленто.
2. Сбросьте фильтры, у Ленто выберите оливковый велюр шириной 210 см и нажмите «Проверить место». Для зоны 210 × 160 см и желаемого прохода 70 см получим 66 см спереди. До заданного прохода не хватает 4 см. В повёрнутом положении по глубине не хватает 50 см.
3. Добавьте тот же вариант в расчёт, установите количество 2 и скачайте файл. Карточка показывает 55 900 ₽ за штуку, итог составляет 111 800 ₽. Перезагрузка страницы сохраняет позиции в браузере.

Демо считает прямоугольный габарит мебели в одном из двух положений. Для дверей, плинтусов, выдвижных частей, высоты, заноса и реального монтажа нужны дополнительные замеры. В смете только мебель. Платежи, оформление заказов и сбор контактов в сценарий демо не входят.

## Оформление и движение

Из FORMA взяты приёмы входа заголовков, реакции кнопок и обновления суммы. В «Мере» знак складывается из арки и трёх делений, а два положения мебели в симуляторе показаны на схемах в масштабе. Движение включено при `prefers-reduced-motion: no-preference`. Иллюстрации мебели демонстрационные. При добавлении исполнения положите в assets файл WebP с именем `идентификатор-модели-идентификатор-исполнения.webp`.

На оформление повлияли [Audo Copenhagen](https://audocph.com/pages/inspiration) для навигации по жилым пространствам, [GUBI](https://gubi.com/en/us/inspiration/editorials/fall-2026-collection) для света и фактур в интерьерной съёмке, [USM](https://www.usm.com/en/about/our-services) для связи конфигуратора с покупательским сценарием.
