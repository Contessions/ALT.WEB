
# ALT AI WEB

Учебный проект веб-студии. Создаём демонстрационные сайты для портфолио и подготовки к первым коммерческим заказам.

## Команда

- Антон — HTML, CSS, JavaScript, разработка и публикация.
- Арсений — Figma, UI/UX, дизайн и визуальная проверка.

## Цель

До 22 ноября 2026 года подготовить:

1. Главную страницу студии.
2. Демонстрационный сайт детейлинга с калькулятором.
3. Демонстрационный сайт мебельной мастерской с предварительным расчётом.

Все кейсы являются демонстрационными и не представляются как реальные клиентские проекты.

## Стартовый оффер

Лендинг для одной услуги малого бизнеса: 15 000 ₽ и 7 дней. В пакет входят структура и содержание, макет, адаптивная разработка, переход в Telegram или звонок и два раунда правок. Срок начинается после согласования структуры и получения материалов. Дополнительные страницы и интерактивные модули рассчитываются отдельно.

## Технологии

- HTML5 — структура страниц.
- CSS3 — оформление и адаптивность.
- JavaScript — интерактивность и расчёты.
- Git и GitHub — контроль версий.
- Figma — дизайн-макеты.

На первом этапе используем HTML, CSS и JavaScript без фреймворков.

## Структура проекта

- `index.html` — главная страница.
- `style.css` — общие стили страниц студии.
- `assets/` — изображения и другие ресурсы.
- `cases/forma/` — демонстрационный сайт детейлинга.
- `cases/furniture/` — демонстрационный сайт мебельной мастерской.
- `AGENTS.md` — инструкции для ИИ-агентов.

## Как запустить

Нужен Node.js 18 или новее. Устанавливать зависимости не требуется.

```bash
npm run dev
```

По умолчанию сайт откроется на `http://127.0.0.1:7100/`. Адрес и порт можно передать параметрами:

```bash
npm run dev -- --host 127.0.0.1 --port 7101
```

Страницы также можно открыть как статические файлы, но локальный сервер лучше подходит для проверки ссылок и ресурсов. Сборка не требуется: готовый к статической публикации код находится в корне проекта.

### Изменение интерактивных модулей

Сборка и дополнительные компиляторы не требуются. Общие функции калькулятора и осмотра лака находятся в `site-module.js`. Учебный прайс, описания услуг и подсказки для брифа редактируются в `cases/forma/catalog.js`. Код осмотра лака — `cases/forma/inspection.js`, логика расчёта и демо-записи — `cases/forma/app.js`.

Шрифты Inter и Lora хранятся локально в `assets/fonts/` вместе с лицензиями SIL Open Font License. Внешние шрифтовые сервисы при загрузке сайта не используются.

## Ограничения

- Оба кейса демонстрационные; отзывы и коммерческие результаты не выдумываются.
- Бриф на странице контактов формирует текст и копирует его, но не отправляет данные на сервер.
- Демо-запись FORMA не бронирует время и не передаёт введённые данные.
- Смета «Меры» сохраняется в текущем браузере через `localStorage`.

## Правила работы

- Изменения сохраняем через Git.
- Новую функциональность разрабатываем в отдельных ветках.
- Перед объединением изменений проверяем результат.
- Не добавляем фиктивные отзывы и результаты.
- Не публикуем пароли, токены и другие секреты.
